# Artifacts

Artifacts is the shared file library for conversations. It separates files an agent generated from files you uploaded.

## Find a file

Open **Artifacts** and switch between **Generated** and **Uploads**. Use the preview action for supported images and documents, or open/download a file for use outside Cynosure.

Generated file links also appear directly beneath the relevant chat response. Opening the artifact from the conversation is the fastest way to preserve its context.

## Keep the library useful

- Use descriptive filenames in your request when the exact name matters.
- Keep source documents in memory spaces when they should be retrieved as knowledge.
- Use chat attachments for files needed only in a particular conversation.
- Back up important generated files outside the app as part of your normal file workflow.

::: info Artifact or memory?
An artifact is a file associated with chat work. A memory document is indexed for semantic retrieval. Uploading an artifact does not automatically make it long-term memory.
:::

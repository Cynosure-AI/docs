# Workspace tour

Cynosure uses a persistent sidebar and a task-focused main panel. The sidebar can collapse to icons when you want more room for a conversation or graph.

## Main areas

| Area | Use it for |
| --- | --- |
| **Chat** | Start conversations and resume recent chats. |
| **Schedule** | Create, run, pause, duplicate, and monitor recurring agent jobs. |
| **Agents** | Create reusable specialists and manage their capabilities. |
| **Artifacts** | Find files generated by agents and files you uploaded. |
| **Memories** | Organize documents, inspect relationships, and explore the knowledge graph. |
| **Recent chats** | Filter and reopen conversations without leaving your current area. |
| **Profile / gear** | See workspace status and open Settings. |

## The chat header

The selector at the upper left switches between **Free Chat** and saved agents. **New Chat** starts a clean conversation. The activity control shows work that is running or awaiting approval, while the notification bell collects completed and actionable events.

## Status cues

- A green workspace status indicates Cynosure’s local server is available.
- A running task appears in workspace activity and can continue while you browse elsewhere.
- An approval indicator means an agent is waiting for you to allow or deny a tool call.
- Memory indexing status appears while uploaded documents are processed.

::: info Desktop data
Cynosure’s configuration and workspace data live on the computer running the desktop app. Back up the workspace before moving computers or making major changes.
:::

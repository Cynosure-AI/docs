# What Cynosure can do

Cynosure is most useful when a conversation can draw on the right files, tools, and specialist agents. The examples below range from simple drafting to multi-step work that combines several capabilities.

::: info Capabilities depend on your setup
An agent can act only through the tools, accounts, local files, and memory spaces you give it access to. Review tool calls and approvals before allowing changes.
:::

## Communication

- Draft a new email from a few bullet points, matching the intended tone and language.
- Search and retrieve messages, summarize long threads, and prepare a reply.
- Organize a crowded inbox or identify messages that can be archived.
- Detect unanswered requests, missing confirmations, required follow-ups, and unfinished tasks.

**Example request:** “Review the messages from this week, list every commitment that still needs a response, and draft the replies. Show them to me before sending anything.”

## Web & research

- Research topics, websites, products, jobs, prices, and offers.
- Extract relevant information from several sources, compare it, and summarize the result.
- Save useful findings as notes, files, or indexed knowledge for later conversations.
- Import todo items from TickNotes and turn them into an actionable plan.

**Example request:** “Compare these three products by price, warranty, repairability, and delivery time. Cite the source for each fact and save the result as a Markdown report.”

## Files & folders

- Analyze, clean up, rename, move, group, and organize local files.
- Find duplicates, outdated files, chaotic structures, and loose downloads.
- Sort media, documents, assets, notes, and project material into a clear hierarchy.
- Convert files into different formats through connected tools.

**Example request:** “Inspect this project folder, propose a cleaner structure, flag duplicates, and show me every planned move before changing a file.”

![An agent proposing a cleaner file hierarchy](../img/sample-conversation-about-file-hierarchy.png)

## Media & documents

- Extract text from screenshots, scanned pages, PDFs, and images.
- Turn unstructured documents into summaries, tables, task lists, or structured notes.
- Generate images and video clips with connected media tools.

**Example request:** “Extract the text from these scanned meeting notes, identify decisions and owners, then create a clean summary and task list.”

## Memory & knowledge

- Index chats, files, notes, and documents into searchable memory spaces.
- Retrieve relevant knowledge automatically while an agent works.
- Clean up, merge, connect, and summarize stored knowledge.
- Explore people, products, concepts, and their relationships in a visual graph.

**Example request:** “Search the product memory for all decisions about offline support, combine duplicate facts, and summarize the remaining open questions.”

![A visual graph of connected knowledge](../img/memory-graph.png)

## Automation

- Control desktop apps, browsers, forms, and files through connected tools.
- Turn a repeated workflow into a scheduled agent job.
- Run multi-step tasks with previews, confirmations, and safety checks.
- Notify you when a scheduled check finds something that needs attention.

**Example request:** “Every weekday morning, check the selected job sites for new matching roles, remove duplicates, update my research note, and notify me only when there is a strong match.”

## Combine capabilities

The strongest workflows cross categories. A research agent might search the web, compare findings, store a report in memory, create follow-up tasks, and schedule a weekly refresh. Start with one controlled task, inspect the result, and add automation after the workflow is reliable.
